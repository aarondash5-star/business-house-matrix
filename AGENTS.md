# Business House Matrix — AI Agent Operating Defaults

This repository has live Matrix systems on Dell/Mac and public source for Pine chat prototypes. A Git commit is **not** a live deployment.

## AW-1: visible automation tag — Pine Manbir only (owner scope correction 2026-10-22)

**Not a fleetwide rule.** The AW-1 label `AUTOMATION | PROJECT | MANBIR | TASK-ID | MODE | STATE` is mandatory only within the separately authorized, automation-owned **Pine Manbir Windows TradingView Controller** GUI session. Dell, Mac, other Matrix agents, generic SSH desktops, Moksha/Andaz browser automation and ordinary personal windows are **not** AW-1 deployment targets. No new tag overlays are required or authorized on those runtimes merely due to AW-1.

- On Manbir only, reconcile exact task receipt, sole writer, lease, ownership, source hash and approved disposable chart before first GUI action; never operate on protected `/chart/JvxzE0Bg/`.
- Missing, hidden, stale or mismatched tag on an owned Manbir target: stop new GUI actions and record `BLOCKED:UNLABELED_WINDOW`; safe read-only diagnostics may continue.
- Never display secrets/private code. No live trading, broker, orders, alerts, unknown source overwrite or publish.
- Reuse merged Matrix AW-1 guard/tests without building a second operator. Historic Dell native fixture screenshots and Mac offline Node tests do **not** prove Manbir enforcement and do not create Dell/Mac rollout obligations.
- Only a native Manbir tagged screenshot, explicit missing-label action refusal, navigation/reload/reconnect, personal-window noninterference and verified rollback with terminal receipts can certify Manbir AW-1.

Scoped canonical rule: https://github.com/karanzing1992/engagement-core/blob/main/docs/AUTOMATION_VISIBLE_WINDOW_TAG_GOLDEN_RULE_20261022.md

## Other standing rules

Reuse working existing implementations before creating replacements; keep private Pine source and protected TradingView charts outside Matrix public code and browser adapters; no uncontrolled native GUI write tools, public publishing, spending, broker actions, production alerts or live trading. Use signed source identity, narrow scope, single-writer receipts and explicit evidence for claims. Do not promote Pine Gold Phase 3 to CERTIFIED while gates remain unverified.
