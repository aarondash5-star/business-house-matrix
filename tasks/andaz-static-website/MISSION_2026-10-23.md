## Intent and implementation order

Build a **complete standalone static HTML/CSS/JS** website for **Andaz Vibe Stay - Arambol, Goa**, separate from WordPress. The website's existing `index.html`, visual direction and Stage A/B browser receipts are references, not a mandate to build a PHP/WordPress theme. Reuse and improve, do not overwrite past working deliverables. Brand journey: **STAY → CONNECT → PLAY → RESET**. Represent dorms, private rooms, long stays, pool, karaoke, bar, community areas and **Moksha Wellness as a separate partner**. Use verified photography or explicit placeholders; no unsupported ratings, tariffs, café claims or fake images passed off as real.

The **entire guest-facing booking UI** must be built now: date selection, date/occupancy validation, room/bed choice, loading, error, unavailable/sold-out/empty results, review/request state and honest enquiry CTA. It must **not** silently claim inventory, price, payment or confirmation. Until a public booking contract is independently certified, offer a reliable **WhatsApp availability enquiry**. Future integration must call **only** an authorized **StayCore booking utility/server adapter**, never expose a staff-only PMS route/token or make WordPress the frontend application dependency. WordPress installation happens in a later, distinct authorized phase.
